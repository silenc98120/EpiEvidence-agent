Langfuse 监测术语速查

只保留当前项目需要的五个概念。

Trace

一次完整用户任务的总记录。当前项目中：一个 task_id 对应一个 Trace。

Span

Trace 内的一段业务工作。当前项目中：一个 LangGraph 节点、一个搜索源调用或一个质量评价批次。

Generation

一次 LLM 请求。它记录模型、Token、耗时、缓存和结果。它应位于发起 LLM 的节点 Span 内。

Loguru

函数级诊断日志。它保存原始异常、文件、函数、行号和 traceback；Langfuse 不替代它。

关联键

task_id 连接 API、TaskCoordinator、LangGraph thread、Langfuse Trace 和 Loguru 日志。搜索和异步批次额外使用 search_run_id、batch_id。
